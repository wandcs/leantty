## 工具与执行责任

采用包含 PR #209（输入与完成观察）、#228（HDC 映射）的干净主线工具，
不从旧维护区复制文件。旧冻结检出、失败报告及已有包身份原样保留。
现有 `release/1.7.0` 与主线分叉，本轮使用 `release/1.7.0-20260924` 做版本准备，
不重置旧分支或带回旧代码。候选精确提交以合入后的外部 manifest 为准。

当前执行者负责每次 ASCII 场景的准备与恢复：

1. 解锁后让目标输入获得焦点，保存系统模式的当前可见证据；仅看到字母输入结果
   或布局缺少模式字段不足以确认。当前明确为英文时不切换。
2. 确认其他模式后才用当前系统菜单选英文，并重新观察；未知时在 Enter 前停止。
3. 沿用普通命令完整内容核对、单次 Enter、独立业务完成观察；秘密输入走现有专用
   通道，不把口令写进布局、日志或证据。
4. 业务清理完成前保持英文可用；finally 只恢复本轮改变的模式，再观察原状及焦点。
   本轮未改变时记录零修改并重新核对。恢复未知不能宣称设备已清洁。

09-19 同设备显式英文准备、中文拼音恢复证据保留在
