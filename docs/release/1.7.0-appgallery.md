# LeanTTY 1.7.0 AppGallery 更新说明

终端改用原生渲染，改善窗口缩放、分屏拖动和输入法交互。支持文本与矩形选择、
搜索、链接打开及约一万行历史滚动。

触摸板慢划更精细、快划加速；改善高系统缩放下的大字号显示、带括号链接识别，
并明确提示过大或暂时无法处理的复制粘贴操作。

Host 和 Key 列表采用多行展示，名称、地址和指纹等长文本自动换行，方便在窄窗口中查看。

改善粘贴权限引导：主动粘贴时可请求系统授权，权限受限时提供明确提示。
取消意外退出后常驻终端的提醒文字，保留标签页与分屏布局恢复及实际连接错误提示。

更新 SSH 依赖，修复部分 ECDSA 私钥导入问题。已信任的主机记录迁入应用私有目录；
升级时自动迁移已有记录，卸载应用会清除信任记录，重新安装后连接时需再次核对主机指纹。
